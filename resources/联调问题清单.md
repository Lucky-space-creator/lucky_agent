## B. Agent 工具调用链路（三个连续命中的 P0）

**【实测】** 后端 SSE 真实事件流：

```
event:thought  {"content":"收到你的请求：你好，用一句话介绍你自己"}
event:token    {"used":216,"model":"deepseek-v4-flash","total":32768}
event:thought  {"content":"开始ACT阶段"}
event:error    {"msg":"模型调用失败：模型调用失败（HTTP 400）","stage":"ACT"}
```

**【实测】** 5 组对照请求直打 deepseek 端点：

| 用例 | 结果 |
|---|---|
| 基线（无工具、无 reasoning_effort） | **200** |
| 仅加 `reasoning_effort: medium` | **200**（排除此项） |
| 工具名 `file.read` + 正确 schema | **400** |
| 工具名 `file_read` + 正确 schema | **200**，模型正确产出 `tool_calls` |
| 工具名 `file_read` + 错误 schema | **400** |

| # | 级 | 问题 | 证据 | 定位 |
|---|---|---|---|---|
| **B1** ✅ | **P0** | **工具名带点号，违反 OpenAI 函数名规范** | 【实测】厂商原文：`Invalid 'tools[0].function.name': string does not match pattern. Expected a string that matches the pattern '^[a-zA-Z0-9_-]+$'.` | `FileOpsToolset.java:77,87,96,107,116,126,135,144`（8 处 `file.read`/`shell.exec` 等）；`SkillToolAdapter.java:36`（`skill.<id>`）；`McpToolAdapter.java:32`（`mcp.<serverId>.<tool>`）。消费方：`ReactEngine.java:168,172`、`ReactEngine.java:297-301` |

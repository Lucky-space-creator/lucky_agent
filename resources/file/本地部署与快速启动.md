# Lucky Agent 本地部署与快速启动

> 产品形态：用户下载服务包，运行一键启动脚本/命令，浏览器访问本地 Web 使用 Agent。类似 OpenClaw 的本地部署思想，不依赖云服务器，不要求用户拥有公网 IP。

## 一、交付形态

- 发布物为 `lucky-agent-<version>.zip`（Windows/macOS/Linux 分平台打包）。
- 包内包含：
  - 后端服务（Spring Boot 单机 jar）；
  - 前端静态资源（Vue 3 + TypeScript 构建产物）；
  - 本机执行臂程序与运行脚本；
  - 一键启动/停止脚本；
  - 默认配置与说明文档。
- 不要求用户注册、不依赖云端账号，不要求公网 IP。

## 二、快速启动

统一入口命令：

```bash
lucky start
lucky stop
lucky status
lucky config
```

Windows 额外提供 `start.bat`，macOS/Linux 提供 `start.sh`，双击或执行脚本即可。

首次启动流程：

1. 检查 Java 17+ 运行环境（后续版本可内置 JRE）；
2. 初始化 `frameworkRoot`（默认 `%LOCALAPPDATA%/lucky_agent` 或 `${user.home}/.lucky_agent`）；
3. 初始化 `workspaceRoot`（首次启动默认 `C:/lucky_agent`，可在 Web 端修改）；
4. 生成本地配置与本地账号；
5. 启动后端并托管前端静态资源；
6. 默认监听 `http://127.0.0.1:8080`，启动成功后自动打开浏览器；
7. 用户在本机浏览器完成模型 Key、工作空间与权限配置。

## 三、本地 Web 访问

- 默认只绑定 `127.0.0.1`，不对外网开放。
- 前端由后端统一托管，用户无需单独启动前端开发服务器。
- Web 端与后端走同一 `AgentChannel` + `Flux<AgentEvent>`，SSE 推送对话、任务列表与进度。
- 如需局域网访问，由用户在配置中显式开启并自行承担暴露风险。

## 四、目录结构

```
lucky-agent/
├── bin/
│   ├── lucky            # CLI/启动命令（macOS/Linux）
│   ├── lucky.bat        # CLI/启动命令（Windows）
│   ├── start.sh
│   └── start.bat
├── backend/
│   └── lucky-agent.jar
├── web/
│   └── dist/            # Vue 构建产物
├── arm/                 # 本机执行臂
├── config/
│   └── application.yml
└── README.md
```

## 五、运行数据

- `frameworkRoot`：框架隐藏目录，配置、记忆、缓存、日志、回退、回收站。
- `workspaceRoot`：用户指定路径，只放用户产物。
- 所有数据在本机，不向任何平台上报。

## 六、安全与隐私

- 默认仅本机访问，`127.0.0.1` 绑定。
- 模型 Key 本地加密落盘。
- 文件/命令操作仍走本机执行臂硬边界。
- 停止服务不影响用户工作空间数据；再次启动自动恢复会话与记忆。

## 七、阶段落点

- Phase 1：交付本地部署包、一键启动脚本、本地 Web 入口。
- Phase 4：CLI 随本地包一并提供，复用同一内核。
- 方案 B（云端服务端 + 本机执行臂）仍作为后续演进项，不改变当前本地部署形态。

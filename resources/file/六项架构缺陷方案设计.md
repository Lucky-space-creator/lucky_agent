# Lucky Agent：六项架构缺陷方案设计（已确认）

> 2026-08-19 确认，采用以下全部推荐方案：1A、2A、3A、4A、5A、6A。

## 1. 部署形态与执行臂架构

**结论**：Phase 1 采用本机进程内/IPC 模式，不引入 WSS 与证书；定义 `ExecutionTransport` 抽象，未来方案 B 时替换为 WSS 实现。

**落地**：
- Phase 1：内核与执行臂同进程或本机 IPC，无网络传输。
- 演进：`ExecutionTransport` 提供 `execute(op)` / `ping()`，本机实现与 WSS 实现可切换。
- 业务模块不感知传输方式，只依赖接口。

## 2. AI 框架能力边界

**结论**：LangChain4j 负责 Agent 循环、工具调用、记忆与 RAG 编排；LangGraph4j 负责工作流 DAG 与多 Agent 图编排；Spring AI 辅助负责模型、嵌入、向量库与可观测性；我们的模块只做策略、规则、适配与通道。

**能力归属矩阵**：

| 能力 | 归属 | 我们模块的职责 |
|---|---|---|
| Agent 推理循环 | LangChain4j | `agent-core` 封装为 PLAN/ACT/ASK 阶段入口 |
| 子代理运行时 | LangChain4j/LangGraph4j | `SubAgentSpec` 配置、任务分解、结果聚合 |
| 会话状态 | LangChain4j | `ConversationStateManager` 适配与事件发布 |
| 工作区存储 | 本地模块 | 目录映射、权限策略、用户配置 |
| 记忆存储 | LangChain4j / 本机文件 | 双轨记忆策略、召回规则、脱敏 |
| 沙箱与执行 | 本机执行臂 | 权限规则、realpath 硬边界、执行臂本地裁决 |
| 模型接入 | Spring AI（辅助）ChatModel → LangChain4j ChatLanguageModel（SpringAiModelAdapter） | 配置、路由、加密、token 计量 |
| 工作流编排 | LangGraph4j StateGraph | DAG 编译、节点调度、上下文作用域 |
| Hook / 权限 / 压缩 | 我们扩展 | 在 LangChain4j/LangGraph4j 生命周期上叠加确定性切面 |
| 嵌入/向量库 | Spring AI（辅助）VectorStore / EmbeddingModel | RAG 数据管道、混合召回、评估闭环 |

## 3. 执行臂权限信任链

**结论**：执行臂本地重新裁决，权限规则同步到执行臂；框架侧裁决结果只作提示，不构成最终权限。

**落地**：
- `PermissionRule` 同步到执行臂本地，执行臂每次操作重新评估 deny/ask/allow。
- 框架侧规则链输出作为上下文和提示，执行臂本地校验为唯一生效源。
- 远端模式不信任上游裁决，防止服务端被攻破后下发 allow。

## 4. 数据落盘根路径

**结论**：frameworkRoot 与 workspaceRoot 分离。

**落地**：
- `frameworkRoot`：框架隐藏目录统一放这里，例如 `%LOCALAPPDATA%/lucky_agent` 或 `${user.home}/.lucky_agent`。
- `workspaceRoot`：用户指定路径，只放用户产物。
- `.trash`、`.config`、`.memory`、`.cache`、`.logs` 等全部在 frameworkRoot 下按用户/工作区分桶。
- `workspaceId ↔ 路径` 映射由 `agent-workspace` 唯一维护，`agent-permission` 只读取。

## 5. Phase 边界

**结论**：接口锁定归 Phase 1，能力实现归 Phase 2。

**落地**：
- Phase 1：定义全部契约和最小运行闭环；Key/URL 加密落盘；CompactionPipeline、Hook、AgentEvent、AgentChannel 只实现最小可用版本。
- Phase 2：补完整权限增强、五级压缩、提示词缓存、熔断、回退等实现。
- Phase 1 文案统一为“不含完整缓存/压缩/回退实现”，不再出现“不含压缩”的矛盾表述。

## 6. 契约 Schema

**结论**：Phase 1 前新增契约文档，作为实现的唯一依据。

**落地**：
- 新增 `resources/file/契约定义.md`，定义 AgentEvent、HookEvent、PermissionRule、SubAgentSpec、AgentChannel 的 JSON Schema 与接口签名。
- 所有契约带版本号，CLI、Web、SDK 共用同一协议。
